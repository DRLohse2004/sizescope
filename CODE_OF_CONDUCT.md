# Code of Conduct

*[Deutsch](CODE_OF_CONDUCT.de.md)*

SizeScope should be a project everyone enjoys taking part in – regardless of experience, background, age, gender, disability, religion or sexual orientation.

## What we expect

- A respectful, friendly tone – also when opinions differ
- Constructive criticism of code and ideas, not of people
- Patience with newcomers and questions
- Taking responsibility for one's own mistakes

## What is not tolerated

- Insults, harassment, threats or demeaning comments
- Sexualized language or imagery
- Publishing other people's private information without their permission
- Trolling and deliberately disrupting discussions

## Scope

This code applies to all project spaces: issues, pull requests, discussions and anywhere someone represents the project publicly.

## Reporting

Please report violations through an issue or a private message on GitHub to the maintainer (DRLohse2004). Reports are treated confidentially. Depending on severity, responses range from a note to a permanent ban from the project.

Based on the ideas of the [Contributor Covenant](https://www.contributor-covenant.org).
